Scrobblr is free and open source. It has exactly one recurring cost: the Last.fm API key that belongs to the app. Since 1 December 2026 Last.fm requires the key owner to hold Pro, so I pay for it yearly. Donations cover that bill and nothing else.

- No tiers, no rewards, no memberships, no monthly tips.

## Why the app needs its own key

A Last.fm API key belongs to an application, not to a user. Asking every user to register one stopped being viable once Last.fm restricted key creation to Pro subscribers. Scrobblr now ships a single key, and users sign in through Last.fm's browser approval page. That is why the project carries this cost at all. See [issue #3](https://github.com/asharahmed/scrobblr/issues/3) and [PR #5](https://github.com/asharahmed/scrobblr/pull/5).
